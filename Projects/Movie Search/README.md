# Movie Search

A small JavaScript project that searches movies by title using a public API and displays results.

## Files
- `index.html` — UI and markup
- `search.js` — fetch and rendering logic

## Run locally
1. Open `index.html` in your browser (no build required).
2. Enter a movie name into the search box and press Enter or click Search.

## Notes
- This is a static front-end project; if the API requires CORS handling, run a local static server:

  ```powershell
  # from the project root
  npx http-server "Projects/Movie Search" -p 8080
  ```
